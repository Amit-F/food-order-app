# FeedMe — frontend

React + Vite + Tailwind frontend for FeedMe. See the [root README](../README.md)
for what the app does and full setup instructions (both backend and frontend).

```bash
npm install
npm run dev      # dev server with HMR
npm run build    # production build
npm run lint
```

Requires `VITE_BACKEND_URL` in `.env` (see root README).
